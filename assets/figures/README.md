# Figure provenance

- `trip_times.png` and `coverage_five_methods.png` are generated by
  `notebooks/StrategicSampling.ipynb` with fixed random seeds.
- `beam_model.svg` and its PNG preview are generated by the notebook for one
  stiffness realization (seed 20261114). The deflected curve comes from the
  existing beam boundary-value solver with its vertical scale magnified.
  Both clamps, uniform unit load, midpoint deflection, and the actual 32
  composite Gauss–Legendre nodes from `rule(8)` are shown. Each of eight equal
  spatial cells uses four Gauss–Legendre nodes.
- `beam_sampling_variability.png` and `beam_sampling_variability.json` are
  generated by the notebook for the synthetic eight-input clamped beam.
  The figure compares IID, scrambled Sobol', LMS+DP scrambled Halton,
  Lattice + baker, and Kronecker + baker, using 64 independent randomizations
  and the same powers of two from 32 through 262144 as the other application
  examples. Each replication reuses prefixes of one randomized design.
  The vertical axis is the sample SD of replicate mean deflections for the
  fixed eight-cell solver, rather than RMSE against a continuum reference.
  The JSON records every replicate estimate, fitted SD exponents over
  4096–262144, solver resolution, and periodization choices. Spatial-resolution
  error requires a separate check. Colors and legend ordering match the other
  application figures.
- `beam_missing_points_rmse.png` and `beam_missing_points_rmse.json` are
  generated by the notebook as a paired comparison of all values against
  64 missing values. Each replication draws one uniform set of 64 indices
  without replacement from the full 2^18-point sample, independently of
  outputs. This set is shared across all five methods and growing prefixes;
  it is independently redrawn only for a new replication. The loss curve
  averages the first n surviving values in original sequence order. Both
  panels show every integer n starting at 64 values actually used, rather
  than only preferred powers of two. The complete panel ends at
  2^18, and the survivor panel at the final available count 2^18−64.
  Early prefixes encounter only whichever losses happen to fall there.
  Both panels show
  identically normalized n^(-1/2) and n^(-1) trend guides, anchored to the
  initial full-prefix IID and Sobol RMSEs rather than fitted to the curves.
  Both panels show empirical RMSE for the mean of the same eight-cell solver.
  An independent reference uses 32 randomized Sobol' replications of 2^22
  points, with its statistical uncertainty checked against the plotted RMSE.
  The JSON retains the reference replications, paired estimates, one loss set
  per replication, attempted prefix lengths for each survivor count, losses
  encountered, lost-value sums, counts, seeds, and
  periodization choices. Spatial-discretization error is separate.
  `beam_missing_points_rmse_all_n.npz` holds the five-method RMSE arrays
  and integer sample-size grids for every plotted n. The JSON's per-replication
  estimates are selected verification checkpoints, not the plotted grid.
- `qmcpy_pypi_activity.jpg` is an actual browser screenshot of
  https://qmcsoftware.org/software/qmcpy.html#pypi-activity, captured November
  14, 2026. It shows the website's November 9 report: 1,247 downloads for
  October 10–November 8 and 9,222 for the available April 8–November 8 daily
  series. The screenshot retains the report date and caveat that counts
  include automated installations and do not represent lifetime downloads.
  The browser screenshot is clipped to the website header and activity
  section; the page content is unchanged.
- `trip_density_cmc.png` is generated by the same notebook using the exact
  same 20,000 trip inputs as `trip_times.png`. It overlays a density-scaled
  histogram with the average of the uniform conditional densities given
  the taxi wait. The conditional formula follows the MATH 565
  `notebooks/applications/AreWeThereYet.ipynb` example. It uses no kernel or
  bandwidth and retains the model's actual density jumps at 47 and 67 minutes.
- `lattice_prefixes.png` is generated by the notebook from the first 64, 97,
  and 128 points of one 128-point randomly shifted, radical-inverse-ordered
  lattice sequence, with seed 565. The 97-point panel is a prefix of this
  sequence, not a new rank-one rule of modulus 97. It shows generator points
  before the baker transform.
- `van_der_corput_prefix.svg` and its PNG companion are generated by the
  notebook's “The first seven base-two van der Corput points” cells. Exact
  rational arithmetic verifies the index-ordered values
  `0, 1/2, 1/4, 3/4, 1/8, 5/8, 3/8`. The one-dimensional number line labels
  every point by its index, with the `i=6` example highlighted. The tick at
  one is an axis reference, not an eighth sequence point.
- `research_all_n_discrepancy.png` is copied without modification from
  `MCQMC26/notebooks/artifacts/figures/special_d64_kuo_new_lattice_new_kronecker_discrepancy.png`
  in Fred J. Hickernell's public MCQMC 2026 repository. It appears in the
  MCQMC 2026 plenary deck's section “Sequences that are good for all n”.
  The figure compares a Kuo lattice, a new lattice, and a new Kronecker
  construction for the older n-weighted discrepancy criterion in d=64. It is
  retained as an archival asset and is no longer displayed in the deck.
  Its legend scores use the historical sample-size weight n.
- `wsesd_prefix_discrepancy.svg` and its PNG companion replace that plot
  with the current 13-dimensional manuscript benchmark, source commit
  `30c1f37af9544779941e054244b8d2da3627f5eb` (November 14, 2026).
  `examples/wsesd/check_discrepancy.py` independently evaluates the supplied
  KCN, CBC–DBD, W_0.01 and W_1/4 vectors; the compact displayed subset is
  KCN, W_0.01 and the exact IID reference. All vectors have maximum
  N=2^20, binary radical-inverse order, and kernel
  product_j(1+j^(-2) B_2({x_j-y_j})). W_0.01 uses sample-size weight
  n^0.98 under the manuscript's n^(1-2 epsilon) convention. The figure
  shows every integer prefix from 1024 through N and the W_0.01/KCN
  ratio distribution as one box plot per open doubling interval, centered
  between its bounding power-of-two x-axis ticks. The box
  spans the 25th–75th percentiles, the line is the median and whiskers show
  the full min–max range across integer n. The IID legend entry is first
  and the legend sits above the curves. The WSESD objective weights use
  omega_n, distinct from the integration estimator weights w_{n,i}. Among non-dyadic sizes,
  94.7147% improve, the median ratio is 0.919964 and worst ratio 1.119134;
  dyadic endpoints are excluded from those summaries. The JSON companion
  records 48 direct pair-sum checks, 132 endpoint comparisons (maximum
  relative difference 5.11e-7), and exact agreement of all eight win counts.
  This verifies the supplied vectors' discrepancies, not their optimization
  or the integration arrays stored outside the manuscript repository.
- The original `iid_uniform_pts.png` and `lattice_pts.png` came from the
  QMCSoftware “Why Add Q to MC?” article and are retained for reference.
- `sampling_schemes_six_dimensions.png` is regenerated by
  `notebooks/StrategicSampling.ipynb`. It extends the MATH 565 Introduction's
  grid/OA/IID/Sobol comparison (source commit `c3feafc` at import) to seven
  designs. All have 64 points in six dimensions, showing coordinates 1 and 2.
  Grid, OA(64,6,8,2), and IID occupy the top row; LMS+DS scrambled Sobol',
  LMS+DP scrambled Halton, a shifted CBC Kronecker sequence, and a randomly shifted Kuo lattice occupy the
  bottom row. The grid/OA construction and original layout derive from
  `MATH565Fall2026/slides/01-introduction.qmd`; all random designs use
  QMCPy and seed 565. Regenerate by running the local notebook.

- `trip_mean_rmse.png`, `keister_mean_rmse.png`, `asian_mean_rmse.png`, and
  `sampling_convergence.json` are generated in `notebooks/StrategicSampling.ipynb`.
  Each comparison includes IID, scrambled Sobol', baker-transformed shifted
  Kronecker, baker-transformed shifted lattice, and LMS+DP
  scrambled Halton, using 64 independent randomizations at powers of two from
  32 through 262144, with prefixes reused within a replication. The fitted
  RMSE powers use sample sizes 4096 through 262144. Trip and Keister have
  analytic means. The one-year arithmetic Asian call has 52 weekly, right-endpoint
  observations and uses an independent
  geometric-control reference (32 scrambles of 2^22 paths); its uncertainty
  is checked against the smallest plotted error. The JSON records all
  comparison estimates, fitted powers, parameters and reference diagnostics.
  After random shifts, the lattice uses the measure-preserving baker/tent map
  before the model's inverse CDF, matching `CubQMCLatticeG`'s default BAKER
  periodization. Kronecker uses the same baker map. These are fixed-budget comparisons, without
  adaptive stopping. The seven-design projection and five-family coverage
  figures show generator points before periodization.
  Reference lines are slope guides, not claimed universal convergence rates.
  Plot legends list methods from larger to smaller geometric-mean RMSE over
  the fitted range, followed by the reference lines in order notation; colors
  stay fixed across models. Grids are omitted and transparent legends sit
  behind the data curves. The Asian Kronecker generating vector is recorded
  in assets/data/README.md.
